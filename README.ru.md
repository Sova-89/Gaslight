# Gaslight — профайлер FPS и нагрузки модов для Hollow Knight

**Покажет, что ест FPS в Hollow Knight и какой мод виноват.**
Профайлер модов: график FPS прямо в игре, время по модам и по методам, HTML-отчёт с лагами и тем, от кого они.

*English version: [README.md](README.md)*

> **Статус: пре-релиз (1.1.0).** Сделан под Modding API для Hollow Knight.
> **Язык интерфейса: русский и английский.** По умолчанию берётся язык системы; переключается прямо в игре (*Options → Mods → Gaslight → Language* или панель на `PageUp`). Касается HUD, описаний настроек, лога и HTML-отчёта.

## Что делает

- **HUD в игре** (клавиша `Insert`): график FPS, FPS, 1% low, сколько мс на кадр едят все моды, сколько ест сам Gaslight, топ-3 мода, последний лаг и кто виноват.
- **Время по методам.** Gaslight находит места, где игра вызывает код мода, и замеряет их: сообщения Unity (`Update`, `FixedUpdate`, `OnGUI`…), корутины, действия PlayMaker, обработчики событий (`On.*`, `ModHooks`, лямбды, кнопки UI) и патчи Harmony (prefix / postfix / finalizer).
- **«От кого лагает».** Каждый кадр, который заметно длиннее обычного, получает вердикт: мод (и какой метод), загрузка сцены, сборщик мусора, несколько модов вместе или «не моды» (игра / видеокарта / система).
- **Отчёт**: `report.html`, `mods.csv`, `timeline.csv`, `spikes.csv` в папке `Reports\<дата-время>\`. Сохраняется сам (примерно раз в минуту на смене сцены, при потере фокуса окном и при выходе), так что окно можно просто закрыть. По `Home` пишется дополнительный снимок в новую папку.
- **Только смотрит.** Gaslight ничего не отключает и не ограничивает ни в игре, ни в других модах. Он только включает и выключает секундомеры.
- **Рассчитан на длинные списки модов** (до ~100): см. [Нагрузка](#нагрузка).

## Установка

1. Скачай `Gaslight.zip` на странице [Releases](../../releases).
2. Распакуй так, чтобы файлы лежали здесь:
   ```
   Hollow Knight\hollow_knight_Data\Managed\Mods\Gaslight\Gaslight.dll
   Hollow Knight\hollow_knight_Data\Managed\Mods\Gaslight\report_template.html
   ```
3. Запусти игру. В логе модов (`ModLog.txt`) появится строка `Gaslight 1.1.0 запущен` (на английском — `Gaslight 1.1.0 started`).

Нужен [Modding API](https://github.com/hk-modding/api) для Hollow Knight. Собрано под Hollow Knight 1.5.78.11833 с Modding API (MonoMod.RuntimeDetour 21.4.29.1). Другие версии не проверялись.

## Клавиши

По умолчанию (меняются в **Options → Mods → Gaslight**: стрелка на строке с клавишей, затем нажми нужную клавишу):

| Клавиша | Действие |
|---|---|
| `Insert` | показать / спрятать HUD |
| `End` | компактный / подробный вид |
| `Home` | сохранить отчёт сейчас |
| `PageUp` | панель настроек на экране (↑↓ выбрать, ←→ менять, Enter — назначить клавишу, Esc — закрыть) |

## Где отчёты

Рядом с `Gaslight.dll`: `Mods\Gaslight\Reports\<дата-время>\report.html`. Открой `report.html` в браузере. Настройки — `Mods\Gaslight\settings.txt` (создаётся при первом запуске).

## Нагрузка

- В настоящем запуске Hollow Knight (6 модов, 2541 замеряемый метод, ~500 fps) сам Gaslight занимал **0,07 мс на кадр**: 3,3 % кадра в 2 мс, то есть около 0,4 % при 60 fps. Один секундомер стоит порядка 100 нс на вызов. В том же запуске установка секундомеров шла около минуты после старта (9 с процессорного времени, растянутых по кадрам).
- Старт: DLL модов читаются с диска через Mono.Cecil (IL «сырыми» байтами, без объектов на каждый метод — почти нет мусора). Просмотр ~27 000 методов в тесте занял ~120 мс. Секундомеры ставятся постепенно в фоне со **средним** бюджетом `StepBudgetPercent = 15` % времени кадра (не больше `StepBudgetMs = 1.5` мс): просадка FPS при установке небольшая, а длинный список модов просто дольше ставится (для ~100 модов — несколько минут). Пока идёт установка, в HUD написано `(ставлю…)`, а лаги за это время помечаются. По окончании в лог пишется, сколько это заняло.
- Ради скорости ничего не отбрасывается: лимитов на число замеров нет (только очень большие предохранители).

## Защита от падения

В модах, собранных под другую версию игры, бывают методы, в сигнатурах которых есть типы, которых больше нет. Если спросить Mono про такой метод через рефлексию, игра может упасть целиком (access violation, `try/catch` не спасает). Поэтому Gaslight:

- читает DLL с диска и не обращается к Mono за методом, пока не убедится, что все типы его сигнатуры существуют (такой метод всё равно не запустится, он просто не замеряется — в логе пишется, сколько таких);
- перед каждым опасным шагом пишет в `scan_guard.txt`, что делает. Если игра всё же упала, при следующем запуске это место попадёт в `quarantine.txt` и будет пропущено (влияет только на замеры; хочешь сбросить — удали файл).

## Честно о точности

- Замеряются **точки входа** в мод. Если мод вызывает метод другого мода или библиотеки, это время засчитывается тому, кто вызвал.
- Если мод перехватывает метод игры (`On.*`) и вызывает оригинал, время самой игры внутри оригинала моду **не засчитывается**: оно считается отдельно («игра внутри хука мода»). Работает, когда хук вызывает оригинал напрямую; если оригинал передан в другой метод, его время всё же попадёт в мод.
- Работа в других потоках не замеряется. Рендер, физика и видеокарта — не моды, в отчёте это «остальное».
- Сам Gaslight тратит немного времени — оно видно отдельной строкой «Gaslight».
- Gaslight показывает **нагрузку и лаги**, а не конфликты модов.

## Настройки, которые стоит знать

| Настройка | Что значит |
|---|---|
| `HookScope=full` (по умолчанию) / `light` | `full` — всё перечисленное выше; `light` — только сообщения Unity и корутины |
| `StepBudgetPercent=15` | какая часть времени кадра в среднем уходит на поиск и установку замеров при старте (только скорость: меньше — меньше просадка FPS, дольше установка) |
| `StepBudgetMs=1.5` | верхний предел того же бюджета, мс на кадр |
| `SpikeMinMs=40` | лаг = кадр длиннее этого значения и в `SpikeFactor` раз длиннее обычного |
| `SelfProtect` | если Gaslight сам (после старта) ест больше `SelfBudgetPercent` % кадра, он перестаёт замерять самые мелкие методы |
| `ProfilerEnabled=false` | только график FPS, без замеров (нужен перезапуск) |
| `ReportAutosaveSec=60` | автосохранение отчёта на смене сцены не чаще, чем раз в столько секунд (`0` — выключено). Ещё сохраняется при потере фокуса окна и, на всякий случай, раз в тройной интервал |
| `Language=auto` / `en` / `ru` | язык интерфейса; `auto` — как в системе. Меняется сразу, в том числе из меню и панели в игре |

## Сборка из исходников

Нужен Windows (используется компилятор C# из .NET Framework 4, код на C# 5) и установленный Hollow Knight:

```
build_hk.bat "C:\Program Files (x86)\Steam\steamapps\common\Hollow Knight"
```

DLL появится в `out\hk\Gaslight.dll`. Без аргумента скрипт берёт переменную окружения `HOLLOWKNIGHT`, затем стандартную папку Steam.

Хочу поменять X → открой файл Y:

| Что менять | Файл |
|---|---|
| клавиши, пороги, настройки (и их описания на русском / английском) | `src/shared/Settings.cs` |
| остальные тексты интерфейса | вызовы `L.T("русский", "English")` в коде (`src/shared/Lang.cs`); у страницы отчёта свои тексты в `report_template.html` |
| как выглядит график и HUD | `src/shared/HudLayout.cs` |
| вид HTML-отчёта | `report_template.html` рядом с DLL (пересборка не нужна) |
| какие методы замерять | `src/shared/IlScanner.cs` |
| какие DLL не трогать | `src/shared/Hooker.cs` (`IgnorePrefixes`) |
| как считается лаг и вердикт | `src/shared/Profiler.cs` |
| что пишется в CSV | `src/shared/ReportWriter.cs` |
| меню модов и поиск DLL в Hollow Knight | `src/hk/GaslightMod.cs` |
